# Лабораторная работа №1 — цветовые модели

Вариант 9: **HSV ↔ XYZ ↔ LAB**.

Приложение позволяет задавать цвет с помощью числовых полей, ползунков или системной палитры. После изменения одной компоненты остальные модели пересчитываются автоматически.

## Возможности

- ручные преобразования HSV ↔ RGB ↔ XYZ ↔ LAB без библиотек конвертации;
- построение матриц RGB ↔ XYZ во время работы программы;
- выбор источника освещения D65, D50 или E;
- стратегии выхода за диапазон sRGB: Clipping и Scaling;
- предупреждение о применённой коррекции;
- динамические градиенты всех ползунков;
- адаптивный интерфейс для настольных и мобильных экранов.

RGB используется только как внутреннее представление для вывода цвета на экран. Он не заменяет три модели варианта.

## Запуск

Приложение не требует установки зависимостей или сборки. Достаточно открыть файл [`index.html`](./index.html) в современном браузере.

После публикации оно доступно по адресу:

<https://vmkzy.github.io/pkg-laboratory/lab-01-color-models/>

## Тесты

Для автоматической проверки нужен Node.js:

```bash
npm test
```

Тесты проверяют матричные операции, построение матриц для всех источников света, известные цвета, обратные преобразования, обработку диапазона и генерацию градиентов.
