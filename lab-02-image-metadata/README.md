# Лабораторная работа №2 — анализ графических файлов

Windows-приложение на C# для ручного чтения метаданных графических файлов. Программа должна работать с BMP, PNG, JPEG, GIF, TIFF и PCX, показывать размеры, DPI, глубину цвета, тип сжатия и состояние файла.

## Требования подгруппы 10А

- Метаданные читаются вручную из байтов файла без библиотек готового разбора изображений.
- Формат определяется по сигнатуре, а не только по расширению.
- Файлы читаются частями: в память не загружается всё изображение.
- Обход папки и разбор файлов выполняются параллельно, интерфейс остаётся отзывчивым.
- Повреждённые и ошибочно переименованные файлы отображаются как проблемные, а не останавливают программу.
- Поддерживается работа с каталогами до 100 000 файлов.

## Архитектура

Решение разделено на три слоя:

1. `Lab2.Presentation` — окно WinForms, таблица результатов, прогресс и предпросмотр.
2. `Lab2.Core` — модели, контракты и в дальнейшем менеджер многопоточного обхода.
3. `Lab2.Infrastructure` — ручные побайтовые парсеры конкретных форматов.

Направление зависимостей:

```text
Presentation ──> Core <── Infrastructure
       └──────────────> Infrastructure (только сборка приложения)
```

`Lab2.Core` не зависит от интерфейса и конкретных парсеров. Поэтому логику можно проверять отдельно.

## Запуск

Из папки `lab-02-image-metadata`:

```powershell
dotnet build Lab2.ImageMetadata.slnx
dotnet run --project src/Lab2.Presentation
```

```powershell
dotnet run --project tests/Lab2.Tests
```
