# Лабораторная работа 2 — анализ графических файлов

Программа на C# и Windows Forms просматривает выбранную папку и показывает сведения о BMP, PNG, JPEG, GIF, TIFF и PCX: размеры, DPI, глубину цвета, сжатие и состояние файла. Формат определяется по сигнатуре, поэтому неверное расширение не мешает распознаванию.

Метаданные читаются вручную из байтов, без библиотек готового разбора изображений. Штатные средства Windows используются только для показа картинки. Для распространённых 8- и 24-битных PCX предпросмотр декодируется отдельно.

## Устройство программы

- `Lab2.Presentation` — окно, таблица, прогресс и предпросмотр;
- `Lab2.Core` — модели и многопоточный обход папки;
- `Lab2.Infrastructure` — побайтовые парсеры форматов.

Обход и обработка идут параллельно. Очереди ограничены по размеру, поэтому список из 100 000 путей не держится целиком в памяти. Таблица работает в виртуальном режиме. Можно отменить сканирование; ошибка одного файла не останавливает остальные.

## Запуск из исходников

Нужны Windows и .NET SDK 10. В папке `lab-02-image-metadata`:

```powershell
dotnet run --project src/Lab2.Presentation
```

Для работы с выданным ZIP сначала распакуйте его в отдельную папку, затем выберите эту папку в окне программы.

## Проверка

```powershell
dotnet run --project tests/Lab2.Tests -c Release
dotnet run --project tests/Lab2.Tests -c Release -- --samples "C:\путь\Для проверки Lab2.zip"
dotnet run --project tests/Lab2.Tests -c Release -- --stress 100000
```

В текущей проверке все тесты прошли. Из выданного архива без ошибок разобраны 24 BMP. Нагрузочный тест обработал 100 000 небольших файлов: 95 000 корректных BMP и 5 000 повреждённых; среди корректных 2 000 имели расширение `.dat` и были распознаны по сигнатуре. Тест создаёт файлы во временной папке и удаляет её после завершения.

## Сборка EXE

Автономный EXE для Windows x64, которому не требуется установленный .NET:

```powershell
dotnet publish src/Lab2.Presentation/Lab2.Presentation.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist/win-x64
```

Готовый файл — `dist/win-x64/Lab2.Presentation.exe`.

Отчёт находится в `docs/report.docx`.
