# Лабораторная работа №2 — анализ графических файлов

Windows-приложение на C# для ручного чтения метаданных графических файлов. Программа должна работать с BMP, PNG, JPEG, GIF, TIFF и PCX, показывать размеры, DPI, глубину цвета, тип сжатия и состояние файла.

## Требования подгруппы 10А

- Метаданные читаются вручную из байтов файла без библиотек готового разбора изображений.
- Формат определяется по сигнатуре, а не только по расширению.
- Файлы читаются частями: в память не загружается всё изображение.
- Обход папки и разбор файлов выполняются параллельно, интерфейс остаётся отзывчивым.
- Повреждённые и ошибочно переименованные файлы отображаются как проблемные, а не останавливают программу.
- Поддерживается работа с каталогами до 100 000 файлов.

## Архитектура

Решение разделено на три слоя:

1. `Lab2.Presentation` — окно WinForms, таблица результатов, прогресс и предпросмотр.
2. `Lab2.Core` — модели, контракты и многопоточный менеджер обхода.
3. `Lab2.Infrastructure` — ручные побайтовые парсеры конкретных форматов.

Направление зависимостей:

```text
Presentation ──> Core <── Infrastructure
       └──────────────> Infrastructure (только сборка приложения)
```

`Lab2.Core` не зависит от интерфейса и конкретных парсеров. Поэтому логику можно проверять отдельно.

## Что готово

- создано решение и четыре проекта;
- настроены зависимости между слоями;
- добавлены общие модели метаданных и прогресса;
- добавлены контракты парсера и менеджера сканирования;
- создан базовый интерфейс выбора папки, таблицы, прогресс-бара и предпросмотра;
- добавлен простой консольный проект проверок без сторонних тестовых библиотек;
- реализован ручной BMP-парсер: сигнатура, заголовки файла и DIB, размеры, глубина,
  разрешение, тип сжатия, палитра, смещение и длина пиксельных данных;
- поддержаны заголовки BITMAPCOREHEADER (12 байт), BITMAPINFOHEADER (40 байт)
  и расширенные варианты 52/56/108/124 байта;
- проверены 24 BMP из выданного архива, включая файлы с нулевым `biSizeImage`;
- реализован потоковый обход папки, ограниченные очереди и параллельная обработка
  файлов; ошибки отдельных файлов не останавливают обход;
- окно показывает результаты по мере обработки, поддерживает отмену, прогресс,
  сведения о файле и предпросмотр выбранного изображения;
- добавлены ручные парсеры PNG, JPEG и GIF: размеры, глубина цвета, сжатие,
  разрешение там, где оно задано, и структурные проверки повреждений.

Для несжатых BMP проверяется длина пиксельного массива с учётом выравнивания строк.
Для сжатых BMP пока проверяются только заголовок, смещения и заявленная длина данных:
сам сжатый поток не декодируется. DPI показывается как неизвестный, если значение
пикселей на метр в файле равно нулю. Расширение файла не используется для распознавания BMP.

Сейчас зарегистрированы BMP, PNG, JPEG и GIF; TIFF и PCX пока помечаются как
«Не поддерживается». Программа распознаёт формат по сигнатуре, поэтому файл с
неверным расширением всё равно читается. Прогресс-бар остаётся неопределённым,
пока идёт поиск файлов, затем показывает долю обработанных. Предпросмотр
использует средства Windows только для отображения выбранного изображения;
метаданные из них не берутся. Чтобы выбрать файлы из выданного ZIP в приложении,
сначала распакуйте архив в папку.

PNG-парсер проверяет порядок блоков, размеры, контрольные суммы IHDR/PLTE/pHYs/IEND
и наличие IEND. JPEG-парсер проверяет сегменты до SOS и завершающий EOI.
GIF-парсер проходит по кадрам и расширениям до завершающего блока. Содержимое
сжатых пикселей не декодируется; повреждение внутри IDAT, JPEG-скана или LZW
может не выявиться при анализе метаданных. DPI JPEG сейчас читается из JFIF APP0;
разрешение, записанное только в EXIF, пока не извлекается.

Следующие этапы: TIFF и PCX, затем стресс-тесты, исправления и отчёт.

## Запуск

Из папки `lab-02-image-metadata`:

```powershell
dotnet build Lab2.ImageMetadata.slnx
dotnet run --project src/Lab2.Presentation
```

Базовые проверки:

```powershell
dotnet run --project tests/Lab2.Tests
```

Проверка на выданном архиве (файлы из него читаются, но не распаковываются на диск):

```powershell
dotnet run --project tests/Lab2.Tests -- --samples "C:\Users\vmkzy\Downloads\Для проверки Lab2.zip"
```

Проверка отдельного изображения, например JPEG:

```powershell
dotnet run --project tests/Lab2.Tests -- --probe-image "C:\path\to\image.jpg"
```

Структура BMP и правила расчёта длины строки сверены с документацией Microsoft:
[BITMAPFILEHEADER](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/ns-wingdi-bitmapfileheader),
[BITMAPINFOHEADER](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/ns-wingdi-bitmapinfoheader).
Структура новых форматов сверена со спецификациями
[PNG](https://www.w3.org/TR/png-3/),
[JFIF](https://www.w3.org/Graphics/JPEG/jfif.pdf) и
[GIF89a](https://www.w3.org/Graphics/GIF/spec-gif89a.txt).
