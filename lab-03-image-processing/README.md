# Лабораторная работа 3 — обработка изображений

Вариант 9, подгруппа 10А. Приложение разрабатывается на C# и Windows Forms.

По варианту нужны глобальная пороговая обработка двумя методами, адаптивная пороговая обработка и сегментация изображения (поиск точек, линий и перепадов яркости). Для подгруппы 10А также предусмотрены ручная работа с пикселями, режимы обработки краёв Clamp и Reflect, интегральное изображение для локальных алгоритмов, обязательный метод Оцу и расширенные возможности для оценки 9–10.

## Структура

- `src/Lab3.Presentation` — окно программы и элементы интерфейса.
- `src/Lab3.PixelAccess` — доступ к массиву пикселей и обработка границ изображения.
- `src/Lab3.Processing` — алгоритмы обработки без кода интерфейса.
- `tests/Lab3.Tests` — проверки алгоритмов.

На этом этапе создан только каркас решения. Обработки изображений и содержательных тестов пока нет.

## Как открыть

Откройте `Lab3.ImageProcessing.slnx` в Visual Studio с установленной нагрузкой **Разработка классических приложений .NET** и выберите запускаемым проектом `Lab3.Presentation`. Из терминала в этой папке можно выполнить:

```powershell
dotnet build Lab3.ImageProcessing.slnx
dotnet run --project src/Lab3.Presentation/Lab3.Presentation.csproj
```

Целевая платформа — современная Windows с .NET 10. Указанное в методичке требование запуска на Windows XP эта конфигурация не выполняет; если преподаватель требует именно XP, платформу потребуется согласовать до реализации алгоритмов.
